# BookShelf API

یک API ساده کتابداری با **FastAPI** که اطلاعات کتاب‌ها را در حافظه نگه می‌دارد و به دیتابیس نیاز ندارد.

> با خاموش یا راه‌اندازی دوباره برنامه، اطلاعات ذخیره‌شده پاک می‌شود. این پروژه برای نمونه‌سازی و یادگیری است.

## نیازمندی‌ها

- Python 3.10 یا بالاتر
- pip

## نصب و اجرا

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی:

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate
```

سپس وابستگی‌ها را نصب و برنامه را اجرا کنید:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

برنامه به‌صورت پیش‌فرض در آدرس `http://127.0.0.1:8000` اجرا می‌شود. مستندات تعاملی Swagger در `/docs` و مستندات ReDoc در `/redoc` در دسترس است.

## APIها

| روش | مسیر | توضیح |
|---|---|---|
| `GET` | `/books` | دریافت فهرست کتاب‌ها |
| `POST` | `/books` | افزودن کتاب |
| `GET` | `/books/{id}` | دریافت یک کتاب |
| `PATCH` | `/books/{id}` | ویرایش بخشی از اطلاعات کتاب |
| `DELETE` | `/books/{id}` | حذف کتاب |

ساختار کتاب شامل `id`، `title` و `author` است. فیلدهای `year` و `isbn` اختیاری‌اند.

### نمونه افزودن کتاب

```bash
curl -X POST http://127.0.0.1:8000/books \
  -H "Content-Type: application/json" \
  -d '{"title":"سمفونی مردگان","author":"عباس معروفی","year":1989,"isbn":"978-964-369-000-0"}'
```

نمونه بدنه برای `PATCH`:

```json
{
  "year": 1990
}
```

شناسه ناموجود پاسخ `404` می‌دهد و درخواست ساخت موفق با کد `201` پاسخ داده می‌شود.
